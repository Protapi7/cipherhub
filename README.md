# CipherHub 🔐

**CipherHub (CipherLab)** is an interactive web-based cryptographic playground and custom language generator. Invent your own cipher systems, map characters to custom symbols, leetspeak, Greek alphabets, Morse code, or emoji, and encode/decode secret messages in real-time.

## ✨ Features

- **Custom Language Generator**: Map every letter and number (A-Z, 0-9) to symbols, numbers, or emojis.
- **Classic Cipher Presets**:
  - Caesar Shift
  - Atbash (A ↔ Z)
  - ROT13
  - Letters to Numbers
  - Greek Alphabet
  - Morse Code
  - Binary (8-bit)
  - Hexadecimal
  - Leetspeak
  - QWERTY Keyboard Shift
- **Interactive Frequency Analysis**: Real-time frequency distribution chart to inspect letter occurrences.
- **Key Export & Import**: Save, backup, and share cipher keys in JSON format.
- **Case Preservation & Formatting**: Multi-character token separation, uppercase markers, 5-character group chunking, and text reversal.
- **Dark / Light Mode**: Built-in responsive theme switcher.
